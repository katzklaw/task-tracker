Shows you what your task completion status is in number/number format appended to the end of your name. Shows what EVERYONE's task completion status and/or number of kills made on the vote screen after you are dead. Adds a "dark mode" to chat. Allows you to adjust the color of chat to any chosen hex code. Each one of these features can be individually toggled on or off.
